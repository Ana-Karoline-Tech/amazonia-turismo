# 🌿 Amazônia Turismo - Landing Page

> Uma landing page moderna e responsiva desenvolvida para uma agência de viagens fictícia, showcaseando as belezas naturais da Amazônia.

## 📋 Descrição do Projeto

Este projeto é uma **landing page profissional** desenvolvida como parte do curso **Recode Pro AI**. O site apresenta uma agência de viagens fictícia chamada "Amazônia Turismo", com foco em experiências turísticas na região amazônica.

A página foi criada com ênfase em:
- ✨ **Interface visual atraente** e intuitiva
- 📱 **Design responsivo** para todos os dispositivos
- 🎨 **Paleta de cores naturais** inspirada na Amazônia
- 📊 **Planejamento de banco de dados** incluído no projeto

## 🚀 Funcionalidades

- **Navegação fluida** com menu interativo
- **Carrossel de imagens** apresentando atrações turísticas
- **Seção de testemunhos** de clientes satisfeitos
- **Galeria de hotéis** de selva com fotos de alta qualidade
- **Informações culinares** sobre pratos típicos amazônicos
- **Formulário de contato** para solicitações
- **Guias turísticos** apresentados de forma visual
- **Fauna e flora** da região em destaque
